# 个人 Web3 工具导航扩展设计

## 目标

将现有 `tools.html` 从少量开发工具入口扩展为个人常用 Web3 导航页。用户可按使用场景快速打开资产管理、交易、网络配置与基础设施服务。

## 范围

- 仅修改 `tools.html`；不创建页面、不修改导航结构。
- 保持当前视觉语言、卡片组件与移动端响应式行为。
- 不添加 JavaScript、外部依赖或第三方图标资源。

## 信息架构

页面顶部保留简介与统计面板：标题更新为“个人 Web3 常用导航”，统计显示 8 个工具与 3 个分类。

工具按以下三组呈现：

1. **资产管理与交易**：Zerion、Hyperliquid、Ondo。
2. **网络与基础设施**：Chainlist、Plasma、Stable、Blockstream。
3. **创建工具**：20Lab。

每个区块均含标题、简短用途说明与工具卡片网格。卡片含工具名、用途标签、中文说明和“打开工具”外链。

## 链接与交互

所有外链在新标签页打开，并设置 `rel="noopener"`。现有卡片悬停、链接按钮和小屏单列布局均继续沿用。

## 验证

- 检查 8 个外链均存在、URL 正确，且分类标题和统计数字一致。
- 确保 HTML 结构完整并保留现有可访问性标签。
- 运行仓库既有 PowerShell 测试。
